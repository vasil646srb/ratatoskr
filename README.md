# Ratatoskr — интернет через Yggdrasil

*Рататоск — белка, что бегает по стволу Иггдрасиля и носит вести между его ветвями и корнями.*

Android-приложение YggProxy и программа `yggproxy` для Linux.

Одно приложение, две роли:

- **Клиент**: системный VPN-слот → `ygghelper tun` (tun2proxy, virtual DNS, UDP через udpgw)
  → `127.0.0.1:10808` → `tcp_node --connect 10808:[сервер]:27080` → Yggdrasil → сервер выхода.
- **Сервер выхода**: `ygghelper server` (SOCKS5 CONNECT + udpgw на 127.0.0.1:10800/7300)
  ← `tcp_node --forward 27080:10800 --open 27080`: порт открыт любому узлу Yggdrasil,
  клиенту нужен только адрес сервера, ключи не настраиваются. Порт 27080 выбран вместо
  обычного SOCKS 1080, чтобы не пересекаться с другими сервисами в сети Yggdrasil.
  Loopback, LAN, ULA и 200::/7 через выход закрыты (кроме самого udpgw); LAN — галочкой.

```
телефон-клиент                                    телефон/хост-сервер
apps → VPN tun → tun2proxy ─socks5→ tcp_node ══ygg══ tcp_node ─→ SOCKS5+udpgw ─→ интернет
```

Страница «Статус» — данные `tcp_node /api/stats` (127.0.0.1:19080): адрес, ключ, корень,
координаты, пиры с RTT, сессии; плюс состояние VPN, связь с сервером (SOCKS-рукопожатие через
оверлей), трафик, счётчики сервера выхода и проверка `generate_204` через выход.

Сборка `tcp_node` всегда с `--features upstream-tls,html`: `tls://`-пиры (свои и из публичного
списка) и поиск в LAN (`--lan-upstream`): узел слушает маяки yggdrasil-go на `[ff02::114]:9001`
и дозванивается до них по TLS на link-local адрес. Приложение держит Wi-Fi `MulticastLock` и
перезапускает узел при подключении к новой сети Wi-Fi/Ethernet (группа вступается при старте).
Состояние поиска — строка «Поиск в LAN» на «Статусе». Настройки — вкладка «Сеть».

Своё приложение исключено из VPN (`addDisallowedApplication`), поэтому ссылки до пиров идут
мимо туннеля. Публичный список пиров качает само приложение (в Android нет curl) и передаёт
`--peers … --no-public`.

## Linux (ПК и серверы)

`desktop/` — программа `yggproxy` для Linux: служба systemd (сервер выхода с ограничением
скорости и VPN-клиент), консольные команды для серверов и окно для рабочего стола. Подробности —
[desktop/README.md](desktop/README.md). Windows — следующим шагом.

## Ограничение скорости

На вкладке «Сервер»: общий лимит сервера и лимит на каждого клиента, отдельно приём и отдача
(Мбит/с, 0 — без ограничения). Применяется сразу, без обрыва соединений: `ygghelper server
--limits FILE` перечитывает файл. Клиента сервер узнаёт по адресу Yggdrasil из строки PROXY v1,
которую передаёт `tcp_node --proxy-protocol`; там же — список клиентов с их трафиком.

## Поиск пиров

Клиент пингует сервер каждые 10 с и, пока пинг выше порога («Сеть»), по одному заменяет самых
медленных пиров. В «Сети» настраиваются порог, пауза между заменами и время проверки нового
пира. На «Статусе» — пиры с текущей скоростью и долей трафика (★ — через него идёт больше всего);
нажатие показывает подробности.

## Сборка

Локально (нужны Android SDK, NDK 27, `cargo install cargo-ndk`,
`rustup target add aarch64-linux-android armv7-linux-androideabi x86_64-linux-android`):

```sh
export ANDROID_NDK_HOME=$ANDROID_SDK_ROOT/ndk/27.3.13750724
TCP_NODE_SRC=~/yggdrasil-lite ./build-native.sh   # tcp_node (yggdrasil-lite, ветка ratatoskr) + ygghelper → app/src/main/jniLibs/*/lib*.so
gradle assembleRelease                  # Gradle 8.11+, compileSdk 35
```

Подпись релиза: переменные `KEYSTORE_FILE`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`;
без них — debug-ключ.

## Использование

1. Сервер: «Сервер» → «Запустить сервер». Появится QR-код со ссылкой
   `yggproxy://c?a=АДРЕС` (порт у всех серверов один — 27080, его не указывают), рядом «Копировать адрес» и «Поделиться».
   Выход открыт всем узлам Yggdrasil, кто знает адрес; локальные сети сервера закрыты.
2. Клиент: «Клиент» → «Сканировать QR сервера» — VPN подключается сразу. Ссылку можно открыть
   и системной камерой (приложение спросит подтверждение), или вставить адрес вручную.

Сервер выхода на Linux/VPS:

```sh
sudo yggproxy install && yggproxy server on      # см. desktop/README.md
```
