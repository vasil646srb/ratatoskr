# Ratatoskr

**Интернет через сеть [Yggdrasil](https://yggdrasil-network.github.io/): VPN-клиент и сервер выхода для Android, Linux и Windows.**

*Рататоск — белка из скандинавской мифологии, которая бегает по стволу мирового древа Иггдрасиль
и носит вести между его ветвями и корнями. Здесь она носит ваш трафик.*

[English version](README_EN.md)

---

## Что это

Ratatoskr превращает любой телефон или компьютер, подключённый к Yggdrasil, в **сервер выхода**:
он раздаёт свой интернет другим узлам сети. Другое устройство становится **клиентом**: весь его
трафик уходит в Yggdrasil и выходит в интернет через сервер.

- **Клиенту нужен только адрес сервера.** Ни ключей, ни настроек: отсканировал QR — подключился.
- **Серверы находятся сами.** Трекеры обходят сеть Yggdrasil и собирают работающие серверы выхода,
  приложение показывает их списком с пингом до каждого.
- **Без root и без отдельного Yggdrasil на телефоне.** Внутри — облегчённый узел
  [yggdrasil-lite](https://github.com/vasil646srb/yggdrasil-lite) (`tcp_node`), совместимый с
  yggdrasil-go.

```
устройство-клиент                                               сервер выхода
приложения → VPN (TUN) → tun2proxy ─SOCKS5→ tcp_node ══ Yggdrasil ══ tcp_node ─→ SOCKS5 + udpgw ─→ интернет
```

## Возможности

| | |
|---|---|
| **Клиент** | весь трафик устройства через VPN; TCP, UDP (QUIC, звонки, игры) через udpgw, IPv4 и IPv6 |
| **Сервер выхода** | открыт любому узлу Yggdrasil на порту **27080**; локальная сеть сервера, loopback и сама Yggdrasil через выход закрыты |
| **Быстрое подключение** | QR-код или ссылка `yggproxy://c?a=АДРЕС` (открывается и системной камерой) |
| **Список серверов** | сохранённые серверы и серверы от трекеров, пинг до каждого и до корня сети |
| **Выбор пиров** | клиент сам меняет пиров Yggdrasil, пока пинг до сервера выше порога |
| **Ограничение скорости** | на весь сервер и на каждого клиента, отдельно приём и отдача; меняется на лету, без обрыва соединений |
| **Статистика** | клиенты сервера и их трафик; пиры Yggdrasil, их скорость и доля трафика |
| **Тест скорости** | как iperf: клиент ↔ сервер через Yggdrasil, 10 с приём и 10 с отдача |
| **Исключения из VPN** | выбор приложений, которые идут мимо VPN |
| **Трекеры** | находят серверы выхода и другие трекеры, синхронизируют списки между собой |
| **Работа в фоне** | сервер не засыпает с выключенным экраном (wake lock, Wi-Fi lock); узел пингует серверы и в свёрнутом приложении |
| **Логи** | экспорт в файл; у каждой остановки записана причина |

## Состав

| Часть | Где | Что делает |
|---|---|---|
| Android-приложение **YggProxy** | `app/` | клиент, сервер, статус, настройки (Kotlin, без сторонних UI-библиотек) |
| `ygghelper` | `ygghelper/` | сервер выхода (SOCKS5, udpgw, лимиты, тест скорости) и сторона tun2proxy для клиента (Rust) |
| `yggproxy` для Linux и Windows | `desktop/` | служба (systemd / служба Windows), консольные команды, окно (egui), трекер — один файл ([подробнее](desktop/README.md)) |
| `tcp_node` | [yggdrasil-lite, ветка `ratatoskr`](https://github.com/vasil646srb/yggdrasil-lite/tree/ratatoskr) | узел Yggdrasil в пространстве пользователя |

## Быстрый старт

### Android

1. Установите APK.
2. **Сервер** (телефон с интернетом): вкладка «Сервер» → «Запустить сервер». Появятся адрес и
   QR-код. Разрешите работу без ограничений батареи, чтобы сервер не засыпал.
3. **Клиент**: вкладка «Клиент» → «Сканировать QR сервера» (или введите адрес, или выберите
   сервер из списка «От трекеров») → «Подключить VPN».

Настройки сети, трекеров и логи — на вкладке «Настройки».

### Linux

Готовые файлы — в [релизах](https://github.com/vasil646srb/ratatoskr/releases/latest): APK, статическая
серверная сборка (любая Ubuntu/Debian x86_64) и версия с окном.

```sh
wget -O yggproxy https://github.com/vasil646srb/ratatoskr/releases/latest/download/yggproxy-server-linux-x86_64
chmod +x yggproxy
sudo ./yggproxy install             # служба systemd, группа yggproxy для управления без sudo
yggproxy server on                  # раздавать интернет
yggproxy qr                         # адрес и QR-код для клиента
yggproxy servers                    # серверы от трекеров с пингом
yggproxy connect                    # подключиться к серверу с наименьшим пингом
yggproxy gui                        # окно
```

Подробно — [desktop/README.md](desktop/README.md).

### Windows

Скачайте `yggproxy-windows-x86_64.exe` из [релизов](https://github.com/vasil646srb/ratatoskr/releases/latest)
и запустите его. Откроется окно; нажмите «Установить и запустить службу» и подтвердите запрос
администратора. Программа скопируется в `C:\Program Files\Ratatoskr`, служба **Ratatoskr** будет
стартовать вместе с Windows, в меню «Пуск» появится ярлык. Те же консольные команды работают в
командной строке: `yggproxy status`, `yggproxy connect`, `yggproxy server on`. Нужна Windows 10/11 x64.

## Как это работает

**Клиент.** VPN-интерфейс отдаёт пакеты в tun2proxy, тот превращает соединения в SOCKS5-запросы к
`127.0.0.1:10808`. `tcp_node` переносит их по Yggdrasil на `[сервер]:27080`. DNS виртуальный:
имена разрешает сервер. UDP идёт внутри того же туннеля через udpgw. На Android само приложение
исключено из VPN, поэтому связи узла с пирами идут мимо туннеля; на Linux для этого служат
пометка `fwmark` и правила маршрутизации, на Windows — привязка сокетов пиров к основному
интерфейсу (`IP_UNICAST_IF`), а туннель (Wintun) получает маршруты `0.0.0.0/1` и `128.0.0.0/1`.

**Сервер.** `tcp_node --forward 27080:10800 --open 27080 --proxy-protocol 27080` принимает
соединения от любого узла и передаёт прокси строку PROXY v1 с Yggdrasil-адресом клиента
(проверенным по его ключу). По нему работают лимиты на клиента и статистика.

**Выбор пиров.** Узел клиента пингует сервер каждые 10 с. Пока пинг выше порога (по умолчанию
100 мс), он заменяет самого медленного пира, проверяет нового заданное время и, если замена не
помогла, ждёт перед следующей вдвое дольше. Порог, пауза и время проверки настраиваются.

**Статистика пиров.** Клиент (приложение и служба на ПК) раз в 10 с записывает, как каждый пир
нёс трафик: пинг до пира, пинг до сервера, пока трафик шёл через этот пир, скорость по реальному
трафику, обрывы. Из этого получается рейтинг; узел в первую очередь подключает лучших
(`tcp_node --prefer-file`) и раз в 2 минуты заменяет худшего пира лучшим свободным. Раз в 30 минут
клиент отправляет трекеру анонимную сводку по пирам (без своего адреса и без сервера выхода,
`POST /report`); трекеры сводят отчёты, обмениваются ими (`GET /peerstats`) и отдают в `/peers`
пиры, отсортированные по общей оценке. Список приоритетов клиента — свои лучшие пиры, затем
рейтинг трекеров.

**Трекеры.** У трекера свой узел Yggdrasil — [yggdrasil-ng](https://github.com/Revertron/Yggdrasil-ng)
как библиотека, со своим стеком TCP: yggdrasil-go, TUN и root не нужны. Удалённым запросом getPeers
он обходит всю сеть, начиная со своих пиров, и проверяет у каждого узла
порт 27080 (SOCKS5 и разрешённый CONNECT на порт теста скорости — так отличается сервер
Ratatoskr) и порт трекера 27081. Список отдаётся по HTTP: `GET /exits`, `GET /trackers`,
`GET /peers` (публичные пиры, проверенные трекером: так узел найдёт пиров, даже если сайт со
списком заблокирован), `GET /info`. Трекеры забирают списки друг у друга и всё полученное перепроверяют сами. Приложение
спрашивает трекеры через свой узел (`tcp_node --socks`) раз в 2 минуты и само узнаёт о новых трекерах.

Расписание трекера (настраивается в `/etc/yggproxy/tracker.json`):

| Что | Как часто |
|---|---|
| поиск других трекеров: опрос `/trackers` у известных | каждые 5 мин |
| поиск других трекеров и серверов: обход всей сети (порты 27080 и 27081) | раз в 30 мин (сам обход ~8 мин, проверка ~12 мин на ~8 500 узлов) |
| перепроверка найденных серверов и трекеров | каждые 5 мин |
| синхронизация с другими трекерами | каждые 5 мин |
| сервер или трекер пропадает из списка | после 2 неудачных проверок подряд (~10 мин) или если не отвечал 24 ч; вернётся, как только снова ответит |
| публичные пиры: скачать список и проверить каждый пир | раз в час |

## Порты

| Порт | Где | Назначение |
|---|---|---|
| **27080** | Yggdrasil | прокси сервера выхода (одинаковый у всех серверов) |
| **27081** | Yggdrasil | API трекера |
| 10808 | 127.0.0.1 | клиентский SOCKS5 → сервер (`tcp_node --connect`) |
| 10810 | 127.0.0.1 | SOCKS5 в сеть Yggdrasil (`tcp_node --socks`) |
| 10800 / 7300 / 7301 | 127.0.0.1 | SOCKS5 выхода / udpgw / тест скорости |
| 19080 | 127.0.0.1 | API узла: `/api/stats`, `/api/peers`, `/api/rtt` |

## Безопасность

- Сервер выхода **открыт всем**, кто знает его адрес: через него можно ходить в интернет от вашего
  имени. Используйте ограничения скорости. Локальная сеть сервера закрыта (если не включена
  галочка «Разрешить клиентам доступ в мою LAN»).
- Трафик внутри Yggdrasil шифруется сетью; от сервера до сайта — как обычно (HTTPS остаётся HTTPS).
- Сервер видит, куда ходят его клиенты, как любой VPN-провайдер. DNS-запросы клиента тоже идут
  через сервер.

## Сборка

Нужны: Rust (stable), Android SDK (platform 35), NDK 27, `cargo-ndk`, Gradle 8.11+, JDK 17.

```sh
git clone -b ratatoskr https://github.com/vasil646srb/yggdrasil-lite ~/yggdrasil-lite
rustup target add aarch64-linux-android armv7-linux-androideabi x86_64-linux-android
cargo install cargo-ndk

# Android
export ANDROID_NDK_HOME=$ANDROID_HOME/ndk/27.3.13750724
TCP_NODE_SRC=~/yggdrasil-lite ./build-native.sh     # tcp_node + ygghelper → app/src/main/jniLibs
gradle assembleRelease                              # подпись: KEYSTORE_FILE, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD

# Windows (кросс-сборка на Linux: rustup target add x86_64-pc-windows-gnu, пакет mingw-w64;
# wintun.dll из https://www.wintun.net, путь — WINTUN_DLL)
(cd ~/yggdrasil-lite && cargo build --release --target x86_64-pc-windows-gnu --bin tcp_node --features upstream-tls,html)
(cd ygghelper && cargo build --release --target x86_64-pc-windows-gnu)
(cd desktop && cargo build --release --target x86_64-pc-windows-gnu)

# Linux
(cd ~/yggdrasil-lite && cargo build --release --bin tcp_node --features upstream-tls,html)
(cd ygghelper && cargo build --release)
(cd desktop && cargo build --release)                                                   # с окном
(cd desktop && cargo build --release --no-default-features --target-dir target/server)  # для серверов
```
